# Изображения мастерской

Исходники оформления страниц хранятся в `assets/site/`:

- `hero/` — крупные композиции и веточки для верхних блоков страниц.
- `decorations/` — отдельные декоративные иллюстрации: подарок, конверт и другие детали.
- `products/` — обложки направлений «Адвент-теги», «Открытки», «Стикеры», общие для главной и страницы «О проекте».
- `templates/` — обложки готовых наборов адвент-тегов.
- `branding/` — логотип проекта.
- `icons/` — общие иконки интерфейса, включая выбор языка.
- `icons/help/` — иконки шагов на вкладке «Начало работы» в справке.

`assets/backgrounds/` зарезервирована для будущих фонов, которые пользователь сможет выбирать в редакторе.

PNG в корне `assets/` — коллекция печатных иллюстраций редактора. Их явные метаданные находятся в `src/data/images.ts`; оформление сайта описано отдельно в `src/data/site-art.ts`.

Имена файлов — на английском в kebab-case. После добавления исходника и записи в справочник выполните `npm run assets:prepare`. Облегчённые WebP для растровых иллюстраций создаются в `public/site/`, SVG копируются без изменения формата. Логотип также обновляет `public/favicon.svg`. Оригиналы остаются без изменений; публичные пути заданы явно в справочнике.
