У этих записей нет TTL. Новый проект после подтверждения заменяет текущий проект только выбранного редактора. Переключение между редакторами не заменяет документ другого типа. Очистка данных сайта удаляет записи. Undo/Redo и введённое в справке описание проблемы находятся только в памяти страницы. Подтверждение условий при запрещённом хранилище остаётся только в памяти текущей страницы; это не серверное доказательство личности или подпись.

Источники проверки: `src/domain/types.ts`, `src/domain/postcards/types.ts`, `src/infrastructure/storage/repository.ts`, `src/infrastructure/storage/postcardSchema.ts`, `src/application/editorStore.ts`, `src/application/postcardStore.ts`, `src/features/onboarding/preferences.ts`, `src/features/onboarding/termsAcceptance.ts`.

Содержимое файлов PDF/PNG/JPG/ZIP — готовый дизайн. Эти файлы не заменяют локальный редактируемый документ и не пополняют историю версий. Экспорт создаёт временный неизменяемый снимок в памяти; после его закрытия и перезагрузки страницы отдельный снимок не сохраняется. Общий обработчик localStorage использует разные ключи и проверяет конфликт другой вкладки до перезаписи каждого документа.

## Ресурсы, поддержка и хостинг

- PT Sans, PT Serif, Bad Script, Pacifico — локальные файлы. Pacifico используется для названия проекта. React, Lucide, jsPDF, OpenType.js и fflate поставляются в сборке. PDF, растровые изображения 300 DPI и ZIP создаются в браузере; текст открыток превращается в контуры локально. Запросы приложения идут за файлами этого же сайта. Аналитика, рекламные пиксели, CDN и Google Fonts не подключены.
- Текущий каталог содержит 207 иллюстраций, 43 графические надписи, 23 фона и 28 элементов декора; это файлы сайта. Выбор ресурса хранится как ID в локальном проекте. Превью облегчают редактор, а экспорт загружает полноразмерные исходники; серверу не передаются содержание текста, состав открыток или параметры их оформления.
- Собственная форма отправки сообщений отсутствует. `mailto:` открывает почтовое приложение. Автор использует Gmail; его обработка описана в [политике Google](https://policies.google.com/privacy?hl=ru).
- Справка составляет отчёт локально; отправка не автоматическая. Буфер обмена получает введённое описание, версию приложения, user agent, статус сохранения и числа ошибок/предупреждений. Тексты карточек и проект автоматически не включаются.
- GitHub Issues доступен при настройке `VITE_GITHUB_ISSUES_URL`; workflow Pages задаёт ссылку на Issues репозитория. Пользователь самостоятельно переходит и публикует обращение, которое может быть публичным. Ссылка на отдельную площадку отзывов пока отсутствует.
- [Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection) прямо подтверждает регистрацию IP-адресов для безопасности. [Общая политика GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) описывает технические данные, сроки и международную обработку. Не следует объявлять GitHub обработчиком локальных дизайнов по поручению автора: такого потока данных приложение не создаёт, наличие применимого DPA не установлено.

## Что требует окончательного решения до публичного релиза

1. **Почтовый адрес и выходные данные.** Решение автора не публиковать адрес соблюдено. Оно не подтверждает достаточность юридических контактов: [§ 18(1) MStV](https://www.gesetze-bayern.de/Content/Document/MStV-18?view=Print) предусматривает имя и адрес для предложений, не ограниченных исключительно личными или семейными целями. Для публичной международной мастерской нужно проверить применимость этой нормы и способ корректного оформления выходных данных. Имя и email сами по себе не объявлены достаточной заменой.
2. **Основания и локальные предпочтения.** Описание основано на фактических функциях; необходимо окончательно оценить каждый доступ к устройству по [§ 25 TDDDG](https://www.gesetze-im-internet.de/ttdsg/__25.html), особенно постоянные отметки тура и уведомления. Отметка условий не подменяет отдельное согласие на обработку, если оно понадобится. [Разъяснения EDPB](https://www.edpb.europa.eu/sme/learn-the-basics/data-protection-basics_en) разграничивают правовые основания.
3. **Почтовый сервис.** Уточнить пригодность используемого Gmail-аккаунта, условия обработки обращений и основания международной передачи; собственная политика сайта не заменяет договорные условия почтового провайдера.

Плашка «Проект политики» и флаг `privacyIsDraft` удалены по прямому указанию автора. Это редакционное изменение, которое не означает завершённую юридическую проверку перечисленных выше вопросов. Сайт не опубликован в рамках этой задачи.
