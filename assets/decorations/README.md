# Декор открыток

Исходники PNG и SVG декоративных элементов добавляются сюда и явно описываются в `src/data/decorations.ts`. Имена файлов — на английском строчными буквами в kebab-case, совпадают с ID. Категории и мотивы задаются вручную после просмотра изображения.

`npm run assets:prepare` сохраняет оригинал в `public/decorations/`, создаёт WebP-превью и обновляет `src/content/decoration-dimensions.json`. Каталог может оставаться пустым; простые круги, звёзды и линии доступны отдельно как геометрический декор.
