# Изображения мастерской

`original-assets/` — локальные оригиналы PNG/SVG. Папка исключена из Git, не публикуется и не нужна для запуска сайта, сборки или CI. Храните её резервную копию отдельно от репозитория.

После переноса прежняя папка `public/` сохранена локально в `original-assets/.previous-public/`. Этот архив не используется сайтом или подготовкой изображений и также исключён из Git.

`assets/` — готовые файлы сайта, которые нужно включать в коммит. Это `publicDir` Vite: dev раздаёт файлы напрямую, production-сборка копирует их без повторного сжатия. Здесь же хранятся шрифты с лицензиями и favicon. Промежуточной папки `public/` больше нет.

| Материалы | Локальные оригиналы | Готовые файлы | Метаданные |
| --- | --- | --- | --- |
| Иллюстрации | `original-assets/` | `assets/art/` | `src/data/images.ts` |
| Надписи | `original-assets/lettering/` | `assets/lettering/` | `src/data/lettering.ts` |
| Фоны | `original-assets/backgrounds/` | `assets/backgrounds/` | `src/data/backgrounds.ts` |
| Декор | `original-assets/decorations/` | `assets/decorations/` | `src/data/decorations.ts` |
| Оформление страниц | `original-assets/site/` | `assets/site/` | `src/data/site-art.ts` |

## Добавление изображений

1. Добавьте оригинал в соответствующую локальную папку. Имя — на английском, строчными буквами, в kebab-case.
2. Добавьте явные метаданные: стабильный ID, `source` с путём в `original-assets/`, `src` с путём относительно `assets/`, названия, категории и поисковые теги. Для PNG-оригинала `src` оканчивается на `.webp`, для SVG — на `.svg`.
3. Вручную выполните `npm run assets:prepare`. Это отдельная операция подготовки материалов; `npm run build` её не запускает.
4. Добавьте в коммит готовые файлы из `assets/`, метаданные и размеры из `src/content/*-dimensions.json`.

Подготовка проверяет метаданные и дубликаты по декодированным пикселям, сохраняет полное разрешение и создаёт небольшие превью. Иллюстрации, фоны и декор сжимаются в WebP с качеством 92 и качеством альфа-канала 100; растровые надписи — без потерь. SVG сохраняются векторными. Оформление страниц получает отдельные WebP с качеством 86.

Состав категорий и подкатегорий задаётся основной принадлежностью изображения, `includeTags` и явным списком `includeImages`. `excludeImages` имеет приоритет: изображение исключается из выбранной подкатегории, но сохраняет описательные теги для общего поиска. Эти правила общие для обоих редакторов.

Локальный кэш `original-assets/.prepared-assets-cache.json` учитывает содержимое исходника и параметры подготовки. Неизменённые изображения с существующими выходными файлами повторно не сжимаются. При замене PNG на SVG удалите устаревший подготовленный WebP, сохранив ID.

Оба редактора и экспорт используют одни и те же готовые изображения в dev и production. Перед экспортом WebP преобразуется в PNG в памяти браузера без дополнительного сжатия с потерями. Папка `dist/` — результат сборки, её не нужно коммитить.

Перенос оригиналов и их исключение из Git не удаляют большие файлы из уже существующей истории коммитов. Изменение истории — отдельная операция.
