# Проверки редактора открыток

Источник сценариев — локальный `requirements/cards-test-cases.md`. Проверки адаптированы к согласованному интерфейсу от 4 ноября 2026 года.

## Соответствие актуальному интерфейсу

- Пять основных вкладок: «Текст», «Иллюстрации», «Декор», «Фон и форма», «Слои». Управление открытками и экспорт доступны как служебные действия на компактных экранах.
- В «Тексте» сначала выбирают «Свой текст» или «Готовые надписи». Смена режима не изменяет документ; выбор графической надписи через слои открывает соответствующий режим.
- Формат меняется в «Фоне и форме», с подтверждением и сохранением координат, размеров и поворотов.
- Контекстное меню исключено согласованным планом. Управление элементами проверяется через панель свойств, «Слои» и клавиатуру.
- Предусмотрен непрозрачный PNG. Проверяется непрозрачность результата, включая изображения с прозрачным исходником.
- Имена экспортируемых файлов фиксированные английские, с нумерацией по порядку проекта. Кириллица и специальные символы проверяются в названии проекта и содержимом текста; настройки произвольного имени файла нет.
- Художественные шаблоны пока не предоставлены. В браузере проверяются три реальных чистых старта, пустое состояние художественного каталога, замена/отмена и добавление. Категорий пустого каталога нет. Независимость и редактируемость элементов композиции проверяются на тестовом шаблоне в домене; он не попадает в пользовательский каталог.

## Запуск

`npm test`, `npm run typecheck`, `npm run lint` и `npm run test:e2e`.

Основные файлы: `src/domain/postcards/commands.test.ts`, `src/application/postcardStore*.test.ts`, `src/application/export/postcard*.test.ts`, `src/rendering/postcard-fonts.test.ts`, `src/rendering/interaction/scene-interaction.test.ts`, `src/infrastructure/pdf/postcards.test.ts`, `tests/e2e/postcards.spec.ts`, `tests/e2e/postcards-export.spec.ts`. Существующие браузерные сценарии тегов и публичной навигации остаются частью регрессии.

Сенсорная проверка выполняется в эмуляции Chromium. Кнопки Undo/Redo проверяются тапами до низкоуровневых CDP-жестов; после каждого жеста одна запись истории проверяется клавиатурными командами. Физические iOS/Android-устройства и диалоги системной печати этим прогоном не проверяются.
