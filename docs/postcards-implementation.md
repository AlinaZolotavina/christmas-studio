# Редактор открыток: реализация

Дата: 4 ноября 2026 года. Основание — локальный согласованный план `requirements/cards-implementation-plan.md` и последующее разрешение пользователя начать разработку.

## Что реализовано

- P00: архитектурные контракты, проверка TTF/контуров, PNG/JPEG 300 DPI и ZIP; зависимости поставляются локально.
- P01/P02: отдельная модель открыток, атомарные команды и ограничения 1–20/100, независимые копии, общие history/store/repository, отдельные ключи, восстановление и защита от перезаписи другой вкладкой.
- P03: явные реестры материалов PNG/SVG, превью и измеренные размеры, три чистых стартовых формата. Дополнительная подборка иллюстраций ссылается на существующие ID.
- P04/P05: общие сцена и Canvas для обоих продуктов, hit testing по порядку слоёв и блокировке, пропорции графики, повороты 15°, несколько текстов, line height, letter spacing, обводка и тень. Локальный PT Sans fallback виден в интерфейсе и проверяется повторно. Геометрия учитывает реальные контуры букв.
- P06/P07: общая оболочка, пять вкладок, контекстные свойства, слои, миниатюры и их порядок, подтверждения изменения формата/шаблона/нового проекта, независимые редакторы, меню направлений и совместимые адреса.
- P08: live-ошибки и отдельная подготовка экспорта, адресация по ID открытки/элемента, 3 мм и 300 DPI, одна группа предупреждений с подтверждением по неизменяемому снимку.
- P09/P10: PDF физического формата текущей открытки или A4 проекта; PNG/JPG 300 DPI и последовательный ZIP. Предпросмотр использует ту же сцену и контуры. После изменения проекта снимок и подтверждение обновляются.
- P11: справка и отдельный тур открыток, фактические публичные описания, технические сведения в политике. Интеграционные проверки и проверка production base path завершены.

## Материалы пользователя

Библиотека содержит 207 уникальных иллюстраций, включая пять Сант и пять изображений эльфов, 43 надписи, 23 фона и 28 элементов декора. Первая дополнительная партия из 31 файла дала 16 новых изображений и 15 повторов существующих. Дополнительно объединён прежний точный дубль альпийской деревни; его ID разрешается в исходную запись для старых проектов. Эти повторы сохранены вне библиотеки в игнорируемом `artifacts/asset-duplicates-2026-11-04/`.

Последующая партия из 60 файлов дала 23 иллюстрации, 8 фонов и 28 декоративных изображений. Единственный повтор `christmas-evergreen-arrangement-with-bells.png` удалён по прямому указанию пользователя; исходная иллюстрация `evergreen-jingle-bells.png` сохранена. Для декора заполнен отдельный `src/data/decorations.ts` с явными названиями RU/EN, категориями, мотивами, тегами и синонимами.

Генератор проверяет совпадение декодированных пикселей до подготовки выходных файлов; имена и PNG-метаданные не скрывают точный повтор. Исходники уникальных изображений не изменяются.

P12 выполнен для предоставленных иллюстраций, надписей, фонов и декора. Художественные шаблоны не предоставлены, поэтому их каталог пуст. Дополнительно к растровому декору доступны геометрические круги, звёзды и линии.

## Проверка

- TypeScript и ESLint проходят.
- `npm test`: 171 тест в 27 файлах проходят. Покрыты домен/сохранение обоих продуктов, совместимость старых ID, трансформации, шрифты/fallback, границы, упаковка A4, контуры PDF и плотность PNG/JPG. Матрица из 24 операций проверяет Undo/Redo и восстановление после автосохранения каждой группы изменений.
- `npm run test:e2e`: все 37 сценариев проходят. Проверены создание и замена проекта, все свойства текста/эффектов и типы фона, независимые документы, слои/lock/Undo, формат без перемещения, копии/перетаскивание миниатюр, scoped export и viewport 320/390/768 portrait/1024 landscape/1440. Сенсорная эмуляция проверяет drag/resize/rotate/pinch, переключение открыток и экспорт.
- Фактический PDF проверяется для всех трёх физических форматов и для проекта из 20 смешанных открыток на 10 листах A4. Браузер декодирует одиночные PNG/JPG и ZIP обоих форматов: порядок, размеры, непрозрачность, 300 DPI.
- Production build с base path `/christmas-studio/` проходит. Браузерная проверка статической сборки по этому пути подтвердила каталог, создание, ленивую загрузку редактора, художественный декор, предпросмотр и PNG 300 DPI без ошибок ресурсов или JavaScript.
- [Таблица покрытия рекомендованных тестов](./postcards-test-coverage.md) фиксирует адаптацию исходного перечня к пяти вкладкам и ограничения проверки на физических устройствах.

Публикация и push не выполнялись. Художественные шаблоны остаются единственным отсутствующим типом наполнения; три чистых стартовых формата доступны.
