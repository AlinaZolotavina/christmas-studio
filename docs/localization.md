# Локализация

`src/locales/ru.json` — рабочий русский словарь приложения. Он загружается через
`src/i18n/index.ts`; компоненты, сообщения редакторов, справка, экспорт и ошибки
обращаются к нему по ключам. Английский перевод находится в `src/locales/en.json`.
Переключатель RU/EN в шапке сохраняет выбор в браузере и перезагружает страницу.

## Разделы словаря

| Раздел | Содержимое |
| --- | --- |
| `common` | Общие действия, название мастерской |
| `navigation` | Меню, ссылки, выбор языка |
| `pages` | Главная, галереи шаблонов, идеи, страница о проекте |
| `projects` | Создание, сохранённый проект, замена, восстановление, уведомления |
| `editor.common`, `editor.tags`, `editor.postcards` | Общие инструменты и настройки редакторов |
| `library` | Подписи библиотеки материалов |
| `templates` | Названия и описания готовых наборов тегов |
| `export`, `validation`, `errors` | Экспорт, предупреждения и ошибки |
| `help`, `onboarding` | Справка и обучение |
| `legal` | Юридические страницы и согласие с условиями |
| `metadata` | Заголовок документа и описание сайта |

Ключ описывает назначение сообщения, например `projects.replace.postcardsDescription`.
При исправлении текста ключ сохраняется. Ключи не вычисляются из русского текста.
Общие подписи стоит переиспользовать, но одинаковые слова с разным смыслом могут
иметь разные ключи.

## Сообщения и параметры

Храните предложение целиком. Не соединяйте переводимые начало, середину и конец
строки в компоненте. Параметры называются по смыслу: `projectName`, `count`, `dpi`,
`width`, `height`, `assetName`.

```tsx
t('projects.replace.postcardsDescription', { projectName: project.name, count: 2 })
```

Переводчик может менять порядок параметров, сохраняя их имена. Значения параметров
не обрабатываются повторно как шаблон. Отсутствующий параметр вызывает явную ошибку.
Тип `MessageKey`, выведенный из русского словаря, ограничивает допустимые ключи в коде.

Для сообщения, зависящего от числа, используется объект форм:

```json
{
  "one": "{count} открытка",
  "few": "{count} открытки",
  "many": "{count} открыток",
  "other": "{count} открытки"
}
```

В английском достаточно `one` и `other`. `Intl.PluralRules` выбирает форму по
числовому параметру `count`; строка `"2"` вместо числа `2` не подходит. Форма `other`
обязательна. Не реализуйте склонения условием `count === 1` в компоненте. Если весь
ключ отсутствует в выбранном языке, используется русский текст с русскими правилами
числа. Если отсутствует отдельная форма, используется `other` того же языка.

## Ссылки, выделения и переносы

Для текста с разметкой используется `rich` из `src/i18n/rich.tsx`:

```tsx
rich('pages.tags.cardCount', { count: 31 }, {
  strong: <strong />,
  span: <span />,
})
```

В переводе такого сообщения сохраняются маркеры `<strong>`, `<span>` и их закрывающие
теги. Аналогично поддерживаются ссылки `<link>…</link>` и переносы `<lineBreak/>`.
Компонент передаёт все разрешённые элементы, адреса ссылок и обработчики. Словарь
может менять порядок элементов, но не добавлять HTML-атрибуты или произвольный HTML.
Пользовательский текст экранируется React. Для этих сообщений нельзя применять
обычный `t`, иначе маркеры останутся видимым текстом.

В текстах пошагового обучения сохранён существующий формат выделений `**текст**`.

## Поддержка переводов

1. Новые и изменённые сообщения обновляйте в `ru.json` и `en.json` с теми же ключами.
2. Сохраняйте параметры и маркеры компонентов. Английские формы числа — `one` и `other`.
   Если русская строка не требует склонения, английская версия этого же ключа всё равно
   может содержать формы числа, как `export.tags.documentSummary`.
3. Для другого языка добавьте словарь `<код-языка>.json` с той же структурой. Vite
   подключит его автоматически, и язык появится в переключателе.

В английской версии приняты названия Christmas Studio, Advent tags и Cards.
Используется британское написание: colour, centre, cosy. FAQ остаются краткими;
названия вкладок и действий в справке совпадают с интерфейсом.

Выбор хранится в `localStorage` под ключом `christmas-studio.locale`. Смена языка
перезагружает страницу: это обновляет также переводы в справочниках, создаваемых при
загрузке модулей. Действующий механизм сохранения редактора обрабатывает уход со
страницы. Язык по умолчанию — русский; для отсутствующих переводов используется
русский словарь. Для неизвестного ключа в обоих словарях выдаётся ошибка.

`lang`, заголовок и описание HTML-документа обновляются при запуске приложения.
Даты в данных хранятся в ISO-формате и выводятся через `Intl.DateTimeFormat`.

## Метаданные и пользовательские данные

Названия иллюстраций, надписей, фонов, декора, категорий и шаблонов открыток уже
содержат `ru`/`en` в `src/data/`. Они выводятся через `localized(...)` и не дублируются
в словаре. Поиск продолжает учитывать оба языка. Содержимое растровых надписей не
переводится автоматически.

Имена сохранённых проектов и введённые пользователем тексты сохраняются дословно.
Названия проектов по умолчанию локализуются при создании нового проекта. Реквизиты
ответственного лица остаются в `legalMetadata.ts`, контактные данные — в
`siteContacts.ts`.

Логика уведомлений опирается на `EditorNotice.type` (`restored`, `save-error` и другие),
а не на содержимое перевода. Поле `notice` в состоянии редактора сохраняется как
текстовое представление для потребителей; типизированные записи находятся в `notices`.

Тесты форматирования и безопасной разметки находятся в `src/i18n/formatter.test.ts`
и `src/i18n/rich.test.tsx`. При этом изменении они не запускались по просьбе пользователя.
