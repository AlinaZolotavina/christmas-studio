# Технические решения реализации

## T00 — основание

- React, TypeScript в strict mode, Vite; локальная разработка и статический артефакт для GitHub Pages. Публикация и push не выполняются.
- Физическая геометрия в миллиметрах, текст и обводка в пунктах. Начальный шаблон — 50 × 80 мм. Zoom не меняет документ.
- A4 portrait, печатные поля 10 мм, минимальный промежуток 3 мм; автоматическая раскладка без масштабирования.
- Защитный лимит текста 6000 символов (по визуальному образцу): ограничивает объём ввода, физическое переполнение проверяется независимо.
- Кандидаты локальных шрифтов: PT Sans, PT Serif и Bad Script из Google Fonts, с кириллицей и лицензией OFL. Одинаковые TTF используются браузером и PDF.
- Неподдерживаемые начертания не синтезируются; шрифт для PDF разрешается до измерения строк.
- Иллюстрации и фон обрезаются силуэтом карточки; переполнение текстового блока показывается и блокирует экспорт. Выход исходной геометрии изображения за силуэт остаётся предупреждением.
- При смене формы сохраняются допустимые координаты отверстия. Если круг отверстия выходит за новый силуэт, операция не фиксируется: необходимо сначала убрать/переместить отверстие.
- Пользователь 1 ноября уточнил: metadata source of truth — `src/data/images.ts`, все характеристики задаются явно; локальный поиск ru/en и фильтры включены в v1. Оригиналы `assets/` пополняются вручную, подготовка производных не назначает категории.

Источники API/размещения: [Vite — static deploy](https://vite.dev/guide/static-deploy.html), [Google Fonts](https://github.com/google/fonts).
