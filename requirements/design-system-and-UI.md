# Advent Tag Studio

## Design System & UI Layout

**Версия:** 0.1  
**Статус:** Draft — согласованные решения, ожидающие визуальной проверки

---

# 1. Общие принципы дизайна

## 1.1. Визуальный стиль

- Минималистичный, чистый и воздушный интерфейс.
- Скандинавская эстетика, ощущение уютной творческой студии.
- Без визуального перегруза и лишнего декора.
- Светлый фон, достаточное количество свободного пространства.
- Единообразие элементов интерфейса и предсказуемое поведение.

## 1.2. Цветовая палитра

| Назначение               | Цвет                           |
| ------------------------ | ------------------------------ |
| Основной акцент          | Deep Forest Green `#315C4C`    |
| Основной фон             | Почти белый                    |
| Левая навигация          | Белый                          |
| Правая панель            | Почти белый                    |
| Рабочая область          | Очень светлый голубовато-серый |
| Акцент шаблонов карточек | Приглушённый клюквенный        |
| Ошибки                   | Функциональный красный         |
| Предупреждения           | Оранжевый / жёлтый             |
| Нейтральные элементы     | Оттенки серого                 |

Клюквенный цвет используется внутри шаблонов карточек, а не для функциональных ошибок.

Точные значения дополнительных цветов и оттенков панелей предстоит определить.

## 1.3. Типографика

- Основной шрифт интерфейса: современный минималистичный sans-serif (например, Inter).
- Заголовки используют то же семейство шрифтов.
- Декоративный шрифт для заголовков интерфейса не используется.
- Шрифты карточек: Serif, Sans-serif, Handwritten.

# 2. Общая структура редактора

## 2.1. Десктоп

Редактор состоит из следующих областей:

1. Левая узкая навигационная панель.
2. Центральная рабочая область с карточкой.
3. Правая панель свойств и настроек.
4. Нижняя горизонтальная лента миниатюр карточек.

В верхней панели располагаются:

- Название проекта.
- Статус сохранения.
- Название текущей карточки.
- Индикатор состояния карточки (ошибки и предупреждения).

Кнопки Undo / Redo и элементы управления масштабом находятся отдельно от основных панелей.

Кнопка экспорта размещается в нижней части правой панели.

## 2.2. Левая навигационная панель

Ширина: 64 px.

Фон: белый.

Содержит только:

- Главная.
- Настройки проекта.
- Справка.

Расположение:

- Главная и Настройки проекта — сверху.
- Справка — закреплена внизу.

Геометрия:

- Кнопки: 40 × 40 px.
- Горизонтальные внутренние отступы: 12 px.
- Отступ сверху: 16 px.
- Расстояние между кнопками: 12 px.
- Скругление: 4 px.
- Иконки: 24 × 24 px.
- Иконки центрированы.

Состояния:

- Неактивная кнопка: зелёная иконка без фона.
- Активная: зелёный фон `#315C4C`, белая иконка.
- Hover: очень светлый серый фон.
- Pressed: фон немного темнее hover.
- Keyboard focus: контрастная двухцветная обводка.

Иконки заполненные, с одинаковой визуальной плотностью и детализацией.

Разделение с рабочей областью:

- Тонкая вертикальная серая линия.
- Ненавязчивая тень справа.

## 2.3. Правая панель

Содержит вкладки:

1. Текст.
2. Изображение.
3. Фон.

В дальнейшем также используются вкладки: 4. Карточки. 5. Экспорт.

Вкладка «Текст» содержит настройки добавления и редактирования текста.

Вкладка «Изображение» — добавление и настройка изображений.

Вкладка «Фон» — настройки фона карточки и управление отверстием.

Вкладка «Карточки» — список карточек проекта.

Вкладка «Экспорт» — настройки экспорта.

На десктопе и планшете в альбомной ориентации все эти вкладки располагаются в правой панели.

# 4. Рабочая область и карточки

## 4.1. Общие правила

Рабочая область представляет собой пространство для редактирования карточки.

Карточка может частично выходить за видимые границы рабочей области. Это необходимо для свободного масштабирования и перемещения.

Перемещение рабочей области:

- Компьютер: ранее определённое управление мышью.
- Сенсорные устройства: перетаскивание одним пальцем по пустому месту карточки.

Масштабирование:

- Кнопками + и −.
- На сенсорных устройствах — жестом двух пальцев.

Разведение пальцев увеличивает масштаб, сведение уменьшает.

## 4.2. Кнопки масштабирования

Располагаются в левом верхнем углу рабочей области.

Вертикальная структура:

1. Текущий масштаб в процентах.
2. Кнопка +.
3. Кнопка −.
4. Иконка «Вписать карточку».

Кнопка «Вписать карточку»:

- Автоматически подбирает масштаб.
- Центрирует карточку в рабочей области.

Блок закреплён относительно рабочей области и не перемещается вместе с карточкой.

## 4.3. Масштаб и положение

- При первом открытии проекта первая карточка автоматически вписывается в рабочую область.
- При переключении карточек масштаб сохраняется.
- Новая карточка автоматически центрируется.
- Положение рабочей области отдельно для каждой карточки не сохраняется.
- При повторном открытии проекта первая карточка снова вписывается в рабочую область.
- При повороте экрана масштаб не меняется.
- При изменении размера окна браузера масштаб также сохраняется.
- Исключение для автоматического вписывания — первое открытие проекта и явное нажатие кнопки «Вписать карточку».

## 4.4. Направляющие и привязка

При перемещении и изменении размера элементов отображаются тонкие направляющие.

Привязка:

- К центру карточки.
- К краям карточки.
- К центрам других элементов.
- К краям других элементов.

Расстояния между элементами числовыми подписями не отображаются.

## 4.5. Выделение элементов

Выбранный элемент:

- Тонкая акцентная рамка.
- Небольшие маркеры изменения размера.
- Без полупрозрачной заливки.

Keyboard focus оформляется отдельной двухцветной обводкой.

На мобильных устройствах пока сохраняются те же маркеры изменения размера, что и на десктопе. Их визуальный размер и удобство использования будут проверены позднее.

# 5. Работа с элементами

## 5.1. Выделение и перемещение

- Одно нажатие по элементу выбирает его.
- Перетаскивание выбранного элемента перемещает его.
- Касание пустого места внутри карточки с перетаскиванием перемещает рабочую область.
- Выбор другого элемента снимает предыдущее выделение.

## 5.2. Редактирование текста

Десктоп:

- Одно нажатие — выделение текстового элемента.
- Двойное нажатие — встроенное редактирование.
- Enter добавляет новую строку.
- Ctrl + Enter завершает редактирование.
- Esc завершает редактирование и сохраняет изменения.
- Клик вне элемента завершает редактирование.

Во время редактирования:

- Рамка элемента остаётся видимой.
- Отображается текстовый курсор.
- Цвет курсора — Deep Forest Green.
- Панель свойств остаётся открытой.
- Настройки применяются в реальном времени.

Горячие клавиши:

- Ctrl + Z — отмена изменений текста во время редактирования.
- Ctrl + A — выделить весь текст текущего элемента.
- Ctrl + C — копировать выделенный фрагмент.
- Ctrl + V — вставить текст.
- Ctrl + X — вырезать выделенный фрагмент.

Вставка:

- Только plain text.
- Форматирование исходного текста не переносится.
- Все переносы строк, включая пустые строки, сохраняются.
- Если превышен лимит символов, вставляется только допустимая начальная часть текста.

## 5.3. Мобильное редактирование текста

На телефоне и планшете в портретной ориентации используется системная клавиатура.

Она вызывается:

- При встроенном редактировании текста на карточке.
- При вводе текста через панель «Текст».

Во время появления клавиатуры:

- Редактируемый текст автоматически остаётся видимым над клавиатурой.
- Верхняя панель и кнопка закрытия настроек остаются доступными.
- После закрытия клавиатуры восстанавливается обычная компоновка.

## 5.4. Изменение текста и переполнение

Если текст не помещается в визуальные границы элемента:

- Размер шрифта автоматически не уменьшается.
- В правой панели отображается предупреждение.
- На карточке появляется небольшой warning icon.

Иконка:

- 16 × 16 px.
- Функциональный красный цвет.
- Положение — верхний левый угол рамки элемента.
- Во время редактирования скрыта.
- После выхода из режима редактирования снова отображается, если переполнение сохраняется.

Проверка выполняется в реальном времени.

Закрытие:

## 6.3. Сенсорные устройства

- Размер: 40 × 40 px.

- Иконка: белые точки.
- Положение: нижний правый угол элемента.
- Отступы: 4 px.

Кнопка:

- Перемещается вместе с выделением.
- Нажатие открывает меню.
- Повторное нажатие закрывает меню.

Контекстное меню открывается под кнопкой с выравниванием по её правому краю.

Длинное нажатие для вызова меню не используется.

# 9. Ошибки и предупреждения карточек

## 9.1. Индикаторы миниатюр

На миниатюре карточки отображаются маркеры:

- Ошибки: красная точка 8 × 8 px.
- Предупреждения: оранжевая точка 8 × 8 px.

Положение: верхний левый угол, отступы 4 px.

Если есть оба типа:

- Сначала красная точка.
- Затем оранжевая.
- Расстояние между ними 2 px.

Отображается по одной точке каждого типа независимо от количества проблем.

Наведение показывает tooltip с типом и количеством проблем.

На сенсорных устройствах tooltip открывается по нажатию и закрывается повторным нажатием или касанием вне него.

## 9.2. Статус текущей карточки

В верхней панели рядом с названием текущей карточки:

- Ошибки — красная иконка и количество.
- Предупреждения — оранжевая иконка и количество.
- Если ошибок и предупреждений нет — зелёная галочка и текст «Проблем нет».

Порядок: сначала ошибки, затем предупреждения.

## 9.3. Модальное окно «Проблемы карточки»

Открывается при нажатии на индикатор проблем.

Показывает только проблемы текущей карточки.

Структура:

- Раздел Errors.
- Раздел Warnings.

Пустой раздел Errors не отображается.

Заголовок: «Проблемы карточки».

Типографика:

- Заголовок: 18 px Bold (700).
- Заголовки секций: 15 px Medium (500).
- Текст и названия элементов: 13 px Regular (400).

Каждая проблема:

- Сначала chip с названием элемента.
- Затем название проблемы.
- Ниже описание.

Chip:

- Светло-серый фон.
- Радиус 4 px.
- Hover — немного изменённый фон.
- Нажатие закрывает модальное окно, переходит к элементу и увеличивает масштаб для удобного просмотра.

Если проблем нет:

- Зелёная галочка.
- Текст «Проблем нет».
- Нажатие ничего не делает.

При повторном открытии список начинается сверху и содержит актуальные проблемы.

# 10. Настройки проекта

Открываются через пункт «Настройки проекта» в левой навигации или полноэкранном меню телефона.

Настройки проекта включают:

- Название проекта.
- Количество карточек.
- Форму карточек.
- Размеры карточек.
- Настройки отверстия.

## 10.1. Формы карточек

В первой версии доступны пять вариантов:

1. Прямоугольник.
2. Квадрат.
3. Круг.
4. Овал.
5. Бирка (Tag).

Произвольные формы не поддерживаются.

## 10.2. Размеры

Пользователь самостоятельно задаёт размеры в сантиметрах.

Набор полей зависит от формы:

- Прямоугольник — ширина и высота.
- Квадрат — длина стороны.
- Круг — диаметр.
- Овал — ширина и высота.
- Бирка — ширина и высота.

## 10.3. Изменение геометрии

Форму и размеры можно менять в любой момент.

Перед применением показывается предупреждение о возможных последствиях:

- Выход элементов за границы карточки.
- Переполнение текста.
- Возникновение ошибок и предупреждений.

После подтверждения:

- Элементы автоматически масштабируются и перемещаются пропорционально новой геометрии.
- Выполняется проверка расположения и переполнения.
- Если элементы всё ещё не помещаются, они остаются в получившемся положении.
- Список ошибок и предупреждений пересчитывается.

# 11. Отверстие в карточке

Отверстие — самостоятельная опция оформления, доступная для любой формы карточки.

## 11.1. Общая настройка проекта

В настройках проекта есть toggle для добавления отверстия.

Если включён:

- Отверстие автоматически добавляется на все новые карточки.
- На существующих карточках отверстие также создаётся.

Если выключен:

- Отверстия удаляются со всех карточек.
- На новые карточки они больше не добавляются.

## 11.2. Внешний вид

Отверстие должно выглядеть как настоящее сквозное отверстие:

- Фон внутри прозрачный.
- Видна рабочая поверхность под ним.
- Это не обычный нарисованный круг.

Начальное положение:

- По центру верхней части карточки.
- С отступом от верхнего края.

## 11.3. Размер

Диаметр:

`min(ширина карточки × 0.07, 5 мм)`

То есть:

- 7% ширины карточки.
- Максимум 5 мм.

При изменении ширины карточки диаметр пересчитывается автоматически.

## 11.4. Положение и управление

- Отверстие можно перемещать.
- Размер менять нельзя.
- За границы карточки перемещать нельзя.
- При изменении формы отверстие сохраняет координаты относительно левого верхнего угла.
- На каждой карточке может быть только одно отверстие.

## 11.5. Управление на уровне карточки

Вкладка «Фон» позволяет:

- Добавить отверстие на отдельную карточку.
- Удалить отверстие на отдельной карточке.

Изменения на одной карточке не влияют на остальные.

- Отступ от края: 16 px.
- При длинном заголовке текст переносится, кнопка остаётся выровненной по верхней строке заголовка.

## 12.4. Содержимое и кнопки

- Заголовок: 18 px, line-height 22 px, weight 600 (кроме специально определённых вариантов).

- Вспомогательный текст: 12 px.
- Расстояние между абзацами: 8 px.
- Между смысловыми секциями: 16 px.

Footer:

- Отступ снизу: 24 px.
- Расстояние от контента: 24 px.
- Кнопки по центру.
- Primary: сплошной зелёный фон.
- Secondary: зелёная обводка.
- Внутренние горизонтальные отступы: 16 px.
- Расстояние между кнопками: 12 px.
- На телефонах кнопки обычно в одну строку, при очень узком экране — вертикально.

При длинном содержимом прокручивается только контент, а заголовок и footer остаются на месте.

# 15. Адаптивная структура

Поведение интерфейса определяется фактической шириной viewport в CSS-пикселях и ориентацией устройства.

## 15.1. Десктоп

Обычная структура редактора:

- Левая навигация.
- Центральная рабочая область.
- Правая панель свойств.
- Нижняя лента карточек.

Правая панель содержит вкладки:

- Текст.
- Изображение.
- Фон.
- Карточки.
- Экспорт.

Кнопка экспорта также остаётся доступной в нижней части панели.

## 15.2. Планшет, альбомная ориентация

Десктопная компоновка, адаптированная под доступную ширину.

- Левая навигация остаётся видимой.
- Правая панель остаётся видимой.
- Все панели, кнопки и отступы становятся компактнее.
- Нижняя лента миниатюр убирается.
- Карточки проекта переносятся в отдельную вкладку правой панели.
- Экспорт также доступен через отдельную вкладку правой панели.

Правая панель содержит:

1. Текст.
2. Изображение.
3. Фон.
4. Карточки.
5. Экспорт.

## 15.3. Планшет, портретная ориентация

Промежуточная компоновка: частично мобильная.

- Верхняя панель сохраняется без бургер-меню.
- Название проекта и статус сохранения остаются сверху.
- Название текущей карточки и её индикатор состояния также остаются в верхней панели, как на десктопе.
- Под верхней панелью располагается рабочая область.
- Внизу — постоянно видимая панель иконок.
- Настройки и список карточек открываются выдвижными панелями снизу вверх.
- Одновременно открыта только одна панель.
- Undo / Redo — компактный горизонтальный островок справа под верхней панелью.
- Safe area учитывается.

## 15.4. Телефон

Полностью мобильная компоновка.

- Верхняя панель с кнопкой-бургером слева.
- Название проекта и иконка статуса сохранения.
- Название текущей карточки и индикатор её состояния переносятся под нижнюю панель.
- Нижняя панель с иконками закреплена у нижнего края.
- Настройки и список карточек открываются снизу вверх.
- Undo / Redo располагаются в фиксированном горизонтальном островке справа под верхней панелью.

# 16. Мобильная верхняя панель

Состав:

- Бургер слева.
- Название проекта.
- Иконка статуса сохранения.

Название проекта:

- Одна строка.
- При недостатке места обрезается многоточием.
- Название сжимается первым.
- Иконка статуса сохранения всегда остаётся видимой.

Высота: 64 px.

Статус сохранения отображается только иконкой, без текста.

## 16.1. Полноэкранное бургер-меню

Меню занимает 100% ширины и высоты экрана.

- Не является боковой панелью.
- Не требует затемнения рабочей области.
- Кнопка закрытия × располагается слева сверху на месте бургера.

Пункты меню:

- Главная.
- Настройки.
- Справка.

Расположение:

- Крупные кнопки вертикально одна под другой.
- Группа кнопок центрирована на экране.
- Кнопки фиксированной ширины.

Геометрия:

- Ширина: 240 px.
- Высота: 56 px.
- Расстояние между кнопками: 16 px.
- Радиус: 8 px.
- Иконка: 24 × 24 px.
- Расстояние между иконкой и текстом: 12 px.

Иконка располагается слева от текста.

«Настройки проекта» открываются в отдельном модальном окне.

Справка доступна только через бургер-меню.

# 17. Мобильная нижняя панель

Постоянно закреплена в нижней части экрана и учитывает safe area.

Все кнопки отображаются только в виде иконок, без текста.

Порядок:

1. Текст.
2. Изображение.
3. Фон.
4. Карточки проекта.
5. Экспорт.

Иконки вкладок настроек и карточек работают как переключатели соответствующих нижних панелей.

Кнопка экспорта запускает соответствующий процесс.

---

# 18. Мобильные нижние панели

Настройки и список карточек открываются поверх рабочей области.

Верхняя панель остаётся видимой.

Максимальная высота панели настроек:

75% от высоты экрана за вычетом высоты верхней панели.

Если содержимое не помещается:

- Включается вертикальная прокрутка.
- Заголовок и кнопка закрытия остаются закреплёнными сверху.

Заголовок располагается слева, кнопка × — справа.

Закрытие:

- Нажатием на ×.
- Нажатием вне панели.

Повторное нажатие на иконку вкладки не закрывает панель.

Других способов закрытия нет.

При открытой панели:

- Рабочая область неактивна.
- Нельзя выделять, перемещать или редактировать элементы.

## 18.1. Панель настроек

Содержит соответствующую выбранную вкладку:

- Текст.
- Изображение.
- Фон.

Панель открывается снизу вверх.

## 18.2. Панель карточек

- Компактнее панели настроек.
- Содержит горизонтальную ленту миниатюр.
- Миниатюры уменьшены относительно десктопа.
- Одновременно полностью видно не менее трёх карточек.
- Части соседних карточек по краям остаются видимыми, чтобы показать возможность горизонтальной прокрутки.
- Активная карточка имеет зелёную рамку и лёгкую тень.
- При открытии списка текущая карточка автоматически центрируется.

После выбора другой карточки:

- Список остаётся открытым.
- Можно быстро переключаться между карточками.
- Закрывается нажатием на рабочую область вне списка или кнопкой ×.

Настройки и список карточек одновременно открыты быть не могут.

## 18.3. Экспорт

На телефоне кнопка экспорта находится последней в нижней панели после кнопки карточек.

Вся нижняя панель использует только иконки, без текста.

---

# 19. Состояние рабочей области при открытой клавиатуре

На телефоне и планшете в портретной ориентации используется системная клавиатура.

При редактировании текста:

- Клавиатура появляется автоматически.
- Редактируемый текст остаётся видимым над клавиатурой.
- Рабочая область временно смещается при необходимости.
- После закрытия клавиатуры восстанавливается обычное положение.

---

# 20. Анимации и доступность

- Учитывается системная настройка Reduce Motion.
- Отдельного переключателя отключения анимаций в интерфейсе v1 не предусматривается.
- Keyboard focus всегда имеет заметную контрастную обводку.
- Сенсорные интерактивные области должны быть удобными для касания.
- Screen-reader-specific improvements рассматриваются для будущих версий.

---

# 21. Параметры, требующие визуальной проверки

Следующие решения пока считаются предварительными:

1. Точные оттенки фоновых панелей и нейтральных цветов.
2. Фактические размеры иконок и кнопок в планшетной компоновке.
3. Визуальный размер маркеров изменения размера на телефонах.
4. Точная высота мобильной панели карточек.
5. Визуальное поведение нижней панели при появлении системной клавиатуры.
6. Реальное удобство масштабирования и перемещения карточки на небольших экранах.
7. Компоновка панели свойств при очень ограниченной ширине.
8. Точная геометрия и визуализация отверстия для разных форм карточек.

Эти параметры следует проверять на реальных размерах экранов и корректировать после создания прототипа.

# 22. Принципиальные ограничения v1

- Нет группировки элементов.
- Нет создания произвольных форм карточек.
- Нет изменения размера отверстия вручную.
- На одной карточке может быть только одно отверстие.
- Нет отдельных пользовательских настроек отключения анимаций.
- Нет отдельного Feedback-раздела в навигации первой версии.
