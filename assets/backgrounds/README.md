# Фоны редактора

Здесь хранятся исходные PNG фоновых изображений для открыток. Явные метаданные находятся в `src/data/backgrounds.ts`: русские и английские названия и теги, категории, мотивы, синонимы, стиль и композиция (`pattern`, `frame` или `texture`). Узор не предполагает бесшовного повторения.

Имена файлов — на английском строчными буквами в kebab-case и совпадают с ID. `npm run assets:prepare` проверяет справочник, копирует полноразмерные PNG в `public/backgrounds/`, создаёт WebP-превью и обновляет `src/content/background-dimensions.json`. Оригиналы сохраняются без изменений.

Иллюстрации для оформления страниц добавляйте в `assets/site/`; структура описана в `assets/README.md`.
