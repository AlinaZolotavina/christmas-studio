# Готовые наборы тегов

Состав наборов задаётся в `src/content/templates.ts`, выбор и перемешивание — в `src/domain/project.ts`. Посторонние изображения из общей библиотеки не подмешиваются при нехватке материала.

- **Зимний сад** (`woodland`): только основная категория «Растения и цветы».
- **Зимняя сказка** (`winter`): дома и пейзажи без русских новогодних традиций и пряничных домиков, а также животные без изображений, входящих в подкатегорию «Птицы».
- **Вкусное Рождество**: «Праздничный стол» и «Бокалы и шампанское», включая горячий шоколад. Доступно 31 уникальное изображение, повторы не используются. Внутренний ID `vintage` оставлен для совместимости с сохранёнными проектами. Старый набор больше не предлагается.
- **Лесные друзья** (`forest-friends`): только основная категория «Животные и птицы», без отдельных елей и лесных пейзажей.
- **Тёплые подарки** (`warm-gifts`): 24 изображения из пользовательского `tests/tags.json`. Набор на 24 содержит весь этот список; набор на 31 дополняется уникальными свечами и коньками. Порядок случайный, соседние изображения имеют разные основные подкатегории. Алгоритм выбирает только те очередные подкатегории, после которых можно закончить чередование.
- **Классическое Рождество** (`classic-christmas`): прежние состав и оформление.

Переименование наборов и обновление подборок не меняют уже сохранённые карточки. Старые ID изображений и шаблонов остаются действительными. Сброс проекта сохраняет выбранные изображения, порядок и идентификаторы карточек.
